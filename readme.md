
# 🎲 بازی حدس عدد | Number Guess Game

---

## 📝 معرفی بازی | Game Introduction

بازی حدس عدد یک بازی ساده و جذاب است که در آن شما باید عددی ۵ رقمی را در تعداد حدس محدود و زمان مشخص حدس بزنید.
هر بار که حدس می‌زنید، بازی به شما سرنخی می‌دهد که چند رقم درست و در جای درست و چند رقم درست ولی در جای اشتباه هستند.

Number Guess is a simple and engaging game where you try to guess a 5-digit number within a limited number of guesses and a fixed time.
Each guess provides clues on how many digits are correct and in the right place, and how many are correct but in the wrong place.

---

## 🚀 ویژگی‌ها | Features

* 🎯 حدس عدد ۵ رقمی | Guess a 5-digit number
* ⏳ محدودیت زمانی و تعداد حدس‌ها | Time and guess limits
* 🕌 پشتیبانی از زبان فارسی و انگلیسی | Supports Persian and English languages
* 🖥️ رابط کاربری گرافیکی با Pygame | Graphical interface using Pygame
* 🔄 تغییر آسان زبان و حالت تمام صفحه | Easy toggle for language and fullscreen mode
* 📋 یادداشت و درباره بازی | Note and About sections
* ♻️ طراحی شده با کدنویسی تمیز و قابل توسعه | Clean, extensible code design

## 🛠️ نحوه اجرا | How to Run

1. ابتدا مطمئن شوید پایتون نصب شده است (نسخه 3.7 به بالا توصیه می‌شود)
   Make sure Python is installed (recommended version 3.7 or higher)
2. نصب پیش‌نیازها:
   Install dependencies:

```bash
pip install pygame arabic_reshaper python-bidi
```

3. اجرای بازی:
   Run the game:

```bash
python main.py
```
