# حدس عدد 🔢🎯 | Number Guess

### توضیحات بازی 🎉

بازی حدس عدد یک بازی ساده و سرگرم‌کننده است که در آن شما باید یک عدد ۵ رقمی را حدس بزنید.
در هر حدس، بازی به شما سرنخ می‌دهد که چند رقم را درست و در جای درست زده‌اید ✅ و چند رقم درست اما در جای اشتباه ❌.
شما ۱۵ حدس 🔢 و محدودیت زمانی ۵۱۰ ثانیه ⏳ دارید تا عدد مخفی را پیدا کنید.
این بازی دارای رابط کاربری دو زبانه فارسی 🇮🇷 و انگلیسی 🇬🇧 است و برای نمایش درست متن فارسی از کتابخانه‌های `arabic_reshaper` و `bidi` استفاده می‌کند 📚.

## English Version 🇬🇧

# Number Guess 🔢🎯

### Game Description 🎉

Number Guess is a simple and fun game where you try to guess a 5-digit secret number 🔍.
After each guess, the game provides clues about how many digits you guessed correctly in the correct position ✅ and how many digits are correct but in the wrong position ❌.
You have 15 guesses 🔢 and a 510-second time limit ⏳ to find the secret number.
The game supports both Persian 🇮🇷 and English 🇬🇧 languages and uses `arabic_reshaper` and `bidi` libraries to properly display Persian text 📚.
